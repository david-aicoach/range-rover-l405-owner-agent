## Evidence promotion standard
A recurring community statement does not become a fact merely because it is repeated. Increase confidence only when one or more of the following is true:
- a JLR bulletin/SSM/workshop source supports the mechanism;
- a government recall/investigation supports the defect;
- several independent specialist sources report the same failure signature;
- the mechanism is mechanically/electrically coherent **and** a discriminating verification test exists.

Every obscure-knowledge record should preserve:
1. model year / derivative applicability;
2. evidence class and confidence;
3. symptoms;
4. the hidden clue;
5. the common false-positive / wrong-parts trap;
6. the safest useful verification test;
7. a source URL.

## Copyright rule
Do not bundle complete copyrighted JLR manuals solely to make the repository self-contained. Store links, structured derived knowledge, short necessary facts and the retrieval map; obtain current full workshop content from authorized JLR sources when needed.
