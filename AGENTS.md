# AGENTS.md

This repository is standalone. Do not import TBHRC organisational rules, routers, memory layers, or private connectors.

**Start here for deployment:** [BOOTSTRAP.md](BOOTSTRAP.md)

## Bootstrap rule
When a user gives you this repository link because they want the agent deployed for themselves or another owner, read and execute `BOOTSTRAP.md`. Default to forking the public repository into the target owner's GitHub account/organisation, then deploy the packaged Skill from that fork and verify it.

The human-facing **“Give this to your AI agent”** handoff must remain only the repository URL. Do not require the human to copy a long setup prompt; the repository owns its own bootstrap instructions.

## Mission
Maintain a portable, evidence-backed owner and diagnostic agent for the full-size Range Rover L405, centred on MY2013 Vogue/Vogue SE and launch-era 2013-2017 vehicles.

## Evidence rule
Prefer JLR owner literature, TOPIx/SSM/LTB material and government recall records. Label specialist/community patterns as secondary evidence. Never present a forum pattern as a confirmed vehicle diagnosis.

## Variant rule
Always distinguish L405 from L494/L322 and identify engine/market/build date before derivative-specific specifications or parts guidance.

## Safety rule
Escalate overheating, oil-pressure, braking, steering, fire/smoke, major coolant loss, or unsafe suspension conditions. Do not encourage invasive high-risk repair procedures for untrained owners.

## Portability rule
Keep the skill functional without private services. Public web access is optional; bundled references must remain useful offline.

## Knowledge architecture
Keep `SKILL.md` as the control plane. Put deep material in one-level references and structured JSONL datasets. Preserve model-year/engine/market applicability and source provenance on every non-obvious claim.

## Hidden-function rule
Document benign owner functions, service modes and read-only engineering diagnostics when evidence exists. Never turn the repository into an immobilizer/alarm bypass, odometer/VIN manipulation, SRS/ABS/steering defeat or unsafe coding guide.

## Research rule
For new obscure knowledge, search manufacturer bulletins/SSMs first, then government-hosted technical records, then specialists and long-running L405 communities. Record the hidden clue, false-positive trap and best proof test rather than copying generic “common problems” lists.
