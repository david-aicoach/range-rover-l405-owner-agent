# Vehicle profile

## Default target
- Vehicle: full-size Range Rover
- Platform/chassis: L405
- Model year: 2013
- Trim context: Vogue / Vogue SE
- Region context: UAE / right-hand drive unless corrected by the user
- Generation: first model year of L405; pre-2018 facelift

## Identity guardrails
Do not confuse:
- Range Rover L405 (full-size) with Range Rover Sport L494.
- 2013 L405 with the outgoing L322, which may also have registrations around the same calendar period.
- Vogue/Vogue SE trim with an engine designation. Engine options differ by market.

## When exact identity matters
Require VIN, engine or build-market confirmation for:
- exact fluid type/capacity;
- oil specification;
- fuse assignment;
- engine-specific leak/failure points;
- part numbers;
- service intervals that vary by engine/market;
- emissions-system questions;
- recall/campaign applicability.

## Useful visual identity
The 2013 L405 is the aluminium-bodied fourth-generation full-size Range Rover introduced for MY2013. Pre-facelift L405 vehicles use the earlier single central infotainment-screen architecture; the major dual-screen Touch Pro Duo interior arrives with the 2018 facelift.
