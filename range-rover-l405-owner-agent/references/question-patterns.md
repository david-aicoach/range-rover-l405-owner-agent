# Example questions and expected behaviour

## Operation
"Where is the bonnet release?"
Answer the location and secondary catch briefly. Confirm RHD/LHD only if location differs materially.

## Warning diagnosis
"Low coolant came on then disappeared."
Rank 2-3 likely causes, require a cold level check, give hot-cap warning, and state the pressure-test next step if it repeats.

## Visual location
"Show me where the coolant level is."
Use an accurate L405 expansion-tank image/handbook illustration where available; warn that engine-bay layout differs by engine.

## Exact specification
"What coolant should I buy?"
Do not guess. Ask for VIN/engine or retrieve VIN-aligned JLR specification.

## Workshop preparation
"What should I tell the mechanic?"
Produce a compact diagnostic brief: exact symptom, frequency, conditions, relevant observations, prior work, requested tests, and no-parts-cannon instruction.
