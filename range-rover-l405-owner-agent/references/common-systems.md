# Common system triage

## Battery / charging
Intermittent warnings across unrelated modules can be caused by low system voltage. For multiple simultaneous warnings, slow cranking, stop-start issues or strange infotainment behaviour, check battery state of health and alternator charging before replacing modules.

Workshop test: battery conductance/load test plus charging-system voltage/current test and full-vehicle DTC scan.

## Air suspension
Separate:
- a warning with normal ride height;
- one corner dropping after parking;
- vehicle slow to raise;
- compressor running excessively;
- vehicle stuck low/high.

Likely categories include air leak, height sensor/linkage, compressor/dryer issue, valve block, wiring/voltage, or control fault. Do not tell an owner to work underneath an air-suspended vehicle without approved support.

## TPMS
Confirm tyre pressures cold against the vehicle placard before treating a TPMS warning as a sensor fault. Temperature changes can lower pressures enough to trigger a warning.

## Drivetrain / gearbox
For "restricted performance", transmission, transfer case or drivetrain messages:
- note exact message wording;
- note whether there is harsh shifting, limp mode, noise or loss of drive;
- obtain JLR-capable DTC scan before guessing a component.

## Warning-message principle
The dashboard message is a symptom channel, not a component diagnosis. Rank causes only after checking corroborating symptoms and stored codes.
