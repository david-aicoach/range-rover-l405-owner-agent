# Source and evidence policy

## Primary manufacturer sources
1. Land Rover iGuide / Digital Handbook
   https://www.ownerinfo.landrover.com/
2. Jaguar Land Rover TOPIx owner/service information
   https://topix.landrover.jlrext.com/

Use VIN-aligned content when possible because model-year pages can cover multiple derivatives and optional equipment.

## Secondary sources
Use specialist communities and independent repair sources only to identify plausible recurring patterns, not to override manufacturer safety/specification data.

Useful categories:
- RangeRovers.net / established Range Rover owner communities
- Land Rover Forums
- reputable independent Land Rover specialists
- government recall databases (market dependent)

## Evidence labels
Use one of these labels mentally and reflect the distinction in wording:
- **Official** — directly supported by JLR owner/service documentation.
- **Verified technical** — supported by credible technical documentation or multiple high-quality sources.
- **Probable** — consistent with known patterns but not proven for this specific vehicle.
- **Speculative** — possible but weakly evidenced; usually omit unless the user asks for exhaustive possibilities.

## Freshness
Owner-handbook procedures are generally stable for a fixed model year, but recall/campaign status, parts supersessions, service bulletins and repair advice can change. Re-check current sources when web access is available.

## Copyright
Do not copy or redistribute complete owner/service manuals in outputs. Paraphrase the needed procedure, quote only small necessary excerpts, and link to the official source.
